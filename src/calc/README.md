# src/calc

Расчётные модули:

- валидация замеров дебитов
- аллокация суточной добычи по скважинам (back-allocation)
- расчёт потерь добычи (deferred production) с разложением по причинам
- DCA (decline curve analysis)

Каждый модуль здесь обязательно сопровождается тестами в `tests/calc/`
с понятными числовыми примерами.
