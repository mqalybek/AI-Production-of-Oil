# src/ingestion

Сбор и нормализация данных о добыче из внешних источников.

Это единственный слой, который знает о формате конкретного источника
(SCADA-выгрузка, ручной ввод оператора, синтетический генератор для
разработки). На выходе — доменные модели из `src/domain/`, дальше
остальной код с форматом источника не работает.

Пока реальных данных нет, здесь же живёт источник на синтетических
данных (генератор — в `scripts/`, а адаптер, отдающий их в том же
интерфейсе, что и будущий реальный источник — здесь).
